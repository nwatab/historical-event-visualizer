# 時代別の国境データの候補（R3b-2 の調査）

2026-09-21 の調査。コードは書いていない（取得と集計は、セッションの作業用ディレクトリの使い捨てスクリプトで行い、リポジトリには入れていない。取得したデータもコミットしていない）。
数値の出所は、すべて「この日に API を実行した出力」。名前の有無は、`name:en` / `name` に英語の部分文字列が含まれるかで判定したもので、別の表記で入っている国家を見落としている可能性がある。

## 結論

- **「100 年刻みのスナップショット」を 1 つのデータで全期間まかなえる候補は、この 3 つの中に無い。**
- **OpenHistoricalMap（OHM）は、ライセンス（CC0）と運用費ゼロの方針には合うが、1500 年より前は穴が大きすぎる。**
  紀元前 500 年にアケメネス朝が無く、800 年に唐が無い（どちらも、全 4,041 relation の中に該当する名前が 1 つも無い）。800 年は 42 件のうち 24 件がヨーロッパで、その大半がブリテン諸島の小王国。
  現実的に使えるのは **1500 年以降（できれば 1800 年以降）**。1914 年は、確認した列強 16 か国がすべて入っている。
- **CShapes 2.0 は 1886〜2019 年（ヨーロッパだけ 1816 年〜）で、非商用・継承の条件つき（CC BY-NC-SA 4.0）。** 近現代を年単位で埋めるには最も整っているが、期間が短く、
  生成データを同じライセンスで配る必要がある（このリポジトリの他のデータは CC0 / パブリックドメイン）。
- **Wikidata の P3896 は使えない。** polity 990 件のうち 10 件しか持っておらず、しかも 1 項目に 1 つの形（ある 1 時点の最大版図など）で、時代ごとの形ではない。
- 実装の判断の材料として: 100 年刻みで全期間を出したいなら、3 候補の外のデータが要る。調査の途中で見つけた `aourednik/historical-basemaps` は、今回の 6 時点と同じ年のファイル
  （`world_bc500` / `world_bc1` / `world_800` / `world_1500` / `world_1800` / `world_1914`。各 0.9〜1.6 MB）を持つが、GitHub の API が返すライセンスは **GPL-3.0**
  （LICENSE の本文と、データの精度は未確認。依頼の範囲外なので、存在とライセンスの欄だけを確認した）。

## 1. OpenHistoricalMap

### ライセンス

出所: https://www.openhistoricalmap.org/copyright （2026-09-21 取得）。

> Except where otherwise noted, OpenHistoricalMap data is dedicated to the public domain under a Creative Commons CC0 dedication.

- 同じページに、個々の地物が CC BY や CC BY-SA のことがあり、その場合は地物の `license=*` タグに書かれている、とある。
- 今回取った admin_level=2 の境界 4,041 relation の `license` タグは、**無し 3,936、CC0-1.0 77、CC0 28** で、CC0 以外は 0 件だった。Overpass の応答の `copyright` 欄も CC0 と書いている。
- クレジットは義務ではないが、歓迎する、と書かれている（README の出典の節に足せばよい）。
- 海岸線・水域は OpenStreetMap 由来（CC BY-SA 2.0）と、同じページの謝辞にある。国境の relation が海岸線の way を含む場合にどう扱われるかは、未確認。

### API で取れるか

取れる。Overpass API（`https://overpass-api.openhistoricalmap.org/api/interpreter`）に、`relation["boundary"="administrative"]["admin_level"="2"]` を問い合わせた。

- OHM は、国境が変わるたびに別の relation を作る方式（アメリカ合衆国が 52 件、ロシア帝国が 38 件、東ローマ帝国が 36 件）。ある年の国境は、`start_date` ≤ 年 < `end_date` の relation を選ぶ。
  `start_date` は 4,041 件すべてにあり、`end_date` が無いのは 217 件。日付は ISO 8601 の文字列で、紀元前は負の年（`-0500`）。Overpass の式で日付を比べると文字列の比較になるので、
  **タグだけを全件取り（10 MB）、手元で年を数値にして選んでから、選んだ relation の geometry を取る**、という 2 段にした。
- 下の表の年は、その年の 7 月 1 日ごろに有効な relation。紀元前 500 年は天文年 −499 として選んだ（OHM の年 0 の扱いは未確認。1 年ずれても結果は変わらない範囲）。

- 大きさの測り方: relation のメンバーの way を、way の id で重複を除いて LineString にした（隣り合う国が共有する国境を 1 回だけ数える。面ではなく線）。簡略化は Douglas–Peucker を way ごとに掛けたもので、
  位相を保つ簡略化（mapshaper など）ではない。**簡略化後の大きさは目安**で、面（Polygon）にすると、共有する国境が 2 回入るぶん大きくなる。
- 簡略化前の点の数は、1914 年で 187 万点。元のデータは、世界全体の表示には細かすぎる（海岸線をそのまま含んでいる）。簡略化すれば、1 時点 0.5〜1.5 MB で、いまのイベントのファイル（1 区間 2 MB 以下）と同じ規模になる。
- 実行時に Overpass を叩くのは「運用費ゼロ・外部に依存しない」の方針に反するので、使うなら、生成時に取得して `public/geo/` にコミットする形になる（1800 年と 1914 年の生の応答は 130〜150 MB。取得に 1 回 1〜2 分）。

### データの質で気づいたこと

- **期間のおかしい relation が混じる。** 紀元前 500 年にも 1 年にも 800 年にも、`Sindh Sultanate`・`Catawba`・`Kingdom of Leinster`・`Uaxactún` が入っている（start_date が極端に早い）。
  スナップショットを作るなら、こうした項目を人が除く表が要る。
- **階層の違うものが同じ admin_level=2 に入っている。** 1500 年のインカ帝国と 4 つのスウユ、マヤの小国家群（ユカタンだけで 20 件前後）、1800 年のカリブ海の植民地が 1 つずつ。「件数」は国家の数ではない。
- relation の開始年の分布: 紀元前は全部で 134 件、1〜399 年は 31 件、400〜999 年は 289 件、1000〜1499 年は 450 件、1500 年代 181、1600 年代 313、1700 年代 448、**1800 年代 915、1900 年代 1,220**。

### 大陸別の密度の偏り（一言ずつ）

- **ヨーロッパ**: 全期間でいちばん密。中世はブリテン諸島の小王国まであるが、ポーランド・リトアニア（1500 年）のような大国が抜けていることもある。
- **アジア**: 中国は王朝によって有無が分かれる（前漢・明・清はあり、唐・宋・元は無い）。インドは 1500 年以降のスルターン朝から。日本は、Japan の名前の relation が 1868 年以降で、1800 年には Tokugawa の名前のものがある（800 年・1500 年は無い）。東南アジアは薄い。
- **アフリカ・中東**: 800 年はガーナ、カネム、アクスム、マクリアがある。1500 年はコンゴ周辺の小王国が密で、マリ・エチオピアが無い。1914 年は植民地の区分で密（71 件で最多）。
- **南北アメリカ**: マヤの都市国家とユカタンの小国家が不釣り合いに密。北米は 1776 年以降の合衆国が、国境の変更ごとに細かい。
- **オセアニア**: 1800 年より前はほぼ無い。

## 3. CShapes 2.0

出所: https://icr.ethz.ch/data/cshapes/ （2026-09-21 取得）の License の節。

> CShapes by Schvitz, Rüegger, Girardin, Cederman, Weidmann, Gleditsch is licensed under a Creative Commons Attribution-NonCommercial-ShareAlike 4.0 International License.

- **商用: 不可**（NonCommercial）。**再配布: 可**。ただし、表示（BY）と、改変したものを同じライセンスで配ること（SA）が条件。
  - このアプリは広告も課金も無い個人のプロジェクトなので、非商用の条件には当たらないと読めるが、「非商用」の範囲の判断は利用者の責任になる。
  - 簡略化した GeoJSON をコミットして GitHub Pages で配ることは「改変して再配布」にあたり、そのファイルは CC BY-NC-SA 4.0 にする必要がある。
    いまのデータは CC0（Wikidata、OHM を使うなら OHM も）とパブリックドメイン（Natural Earth）、Wikipedia 由来は記事名と URL だけなので、**リポジトリの中に非商用限定のデータが初めて入る**ことになる。
  - 引用の指定がある（Schvitz et al. 2022, Journal of Conflict Resolution 66(1)）。
- 範囲: 同じページの説明によれば、独立国と従属地域の国境と首都を 1886〜2019 年、CShapes-Europe は 1816 年から。GeoJSON で配布されている（`CShapes-2.0.geojson`）。ファイルは取得していない（大きさと簡略化の程度は未確認）。
- 国境の変更が日付つきで入っているので、1886 年以降なら 100 年刻みどころか年単位で出せる。ただし、このアプリの年の範囲（紀元前 3001〜2025 年）の 97% は範囲外。

## 実装の指示を出す前に決めること

1. 国境を出す期間を絞るか（OHM だけなら 1500 年以降、または 1800 年以降）、全期間に出すために 3 候補の外のデータ（ライセンスの確認が要る）を調べるか。
2. 面で塗るのか、線だけ引くのか。線だけなら、共有する国境が 1 回で済み、期間のおかしい relation や階層の混在の影響も見えにくい。
3. OHM を使う場合の、人が持つ表（除く relation、足りない国家の扱い）。place-overrides と同じく、根拠を書いてコミットする形になる。
